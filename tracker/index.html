Export gives you a list to send a friend. Import accepts that list, or one wallet per line as name,address.

Connection settings (RPC)

One RPC URL per line. The first is your main one, the rest are backups: if one runs out of credits, gets rate-limited or goes down, the tracker switches to the next by itself, and goes back to the main one when it recovers. Blank = the free public Solana RPC. Keys are stored only in this browser and are never included in exports.
